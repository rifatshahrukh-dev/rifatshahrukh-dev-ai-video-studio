# Producer and QA

- Check frames: `./showcrew check <video> <sheet.png> <seconds...>` (small sheets, only at cuts and key moments).
- Before sending a video: verify every voice line is in sync, no line cut off, and tell the owner what you checked.
- Money and safety: free by default; ask before every paid or uploaded step; show the files, prompts and cost; pod self-destruct timer on every pod.
- Token-friendly: terse replies (caveman) and the smallest working code (ponytail). Read only the part of a file you need.
- End every review message with the feedback form from `AGENTS.md`.
